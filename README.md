# 단면 / Cross-Section

> 교과서의 경제 그래프는 고차원 구조의 **단면**이다.

경제학 학부 커리큘럼을 개념 그래프(온톨로지) 위에서 다시 설계하고, 그 설계를 공간으로 보여주는 프로젝트의 런칭 사이트.

- **2D (종이)** — 교과서처럼 단순화된 그래프. 그 자체로 완결된, 좋은 틀이다.
- **Expo (공간)** — 같은 그래프를 들어 올리면 그 단순화가 무엇을 접어 두었는지 드러난다. 곡면, 시간축, 미분방정식, 행렬. 그래서 경제수학을 왜 배워야 하는지가 보인다.

### 사이트 구조 (2026-10-30): 세 부분 + 교재 페이지

`prototype/traditional/`은 이제 여러 페이지로 된 정적 사이트다. 경로는 나중에 Remix 3 라우트로 그대로 옮길 수 있게 맞췄다.

| 페이지 | 내용 |
|---|---|
| `index.html` | 세 부분 소개 + 17개 과목 교재로 가는 문 |
| `classical.html` | **1부, 고전 교재**: 주체와 시장이 하나씩 더해지는 8단계와 그림 30개. 그림마다 '고정된 것'과 그 축을 따라간 설명이 있다. 표제란의 **Fold the page into space**가 유일한 3D 모드다(`fold.js`). 페이지 전체가 리본으로 접히고, 그림이 읽는 줄에 오면 그 그림이 고정해 둔 축(`p1-fold.js`)이 제자리에서 솟는다. Esc나 같은 버튼으로 같은 자리의 평면으로 돌아온다. 옛 페이지는 `classical-v1.html`. |
| `beyond.html` | **2부, 평면 밖으로**: 1부 맺음말의 가정을 하나씩 푸는 다섯 절이다(누가 누구와 거래하나, 사슬, 대표 기업은 없다, 실제 사람의 게임, 은행 간 전염). 절마다 1부의 출발 그림과 'Held fixed'가 있고, 세 그림은 독자가 설정을 바꿀 수 있다. 접으면 고전 그림에 없는 차원이 솟는다(`p2-figs.js`, `p2-fold.js`, `p2-models.js`). 끝에 교재 프로젝트를 둔다. 옛 페이지는 `beyond-v1.html`. |
| `archive.html` | **3부, 새 아카이브**: 제안 글, 아카이브 평면도(방법·제도·시장·주체 네 층, 방 24개, 각 방은 과목으로 가는 링크), 고전과 현대를 잇는 가정 표, 세 갈래 길, 교재 목록. 접으면 평면도가 층층이 선 건물이 되고, 방 이름이 누를 수 있는 문이 된다(`p3-figs.js`, `p3-fold.js`). 옛 페이지는 `archive-v1.html`. |
| `course.html?c=<id>` | 과목별 교재: 주차 사다리, 이 과목의 3D 유도, 다른 과목과 만나는 교차점, 다음에 읽을 것(실라버스, 교재) |

### 프로토타입 ②: `prototype/traditional/` (최신)

*How economics is taught*. 기존 학부 커리큘럼(원론 → 경제수학 → 미시 → 거시 → 계량 → 각론)이 왜 그 순서로 쌓이는지 설명하는 영어 페이지다.

- **평면**: 엔지니어링 계산 용지 위의 도면이다. 교과서식 SVG 그림 17개, 방주, 장별 수식 번호, 각론 부품표가 있고, 오른쪽 아래 표제란이 지금 시트와 지금까지 등장한 차원·주체·방정식 수를 보여준다.
- **Unfold**: 페이지 전체를 html-in-canvas(`GPUQueue.copyElementImageToTexture`)로 캡처한다. 약 2,000px 높이의 타일 여러 장(페이지 약 47k px)에 밉맵과 비등방 필터를 쓴다. 캡처한 도면은 청사진 공간 속에서 뒤로 눕고 휜다. 각 그림이 읽는 줄에 닿으면 그 그림이 접어 둔 차원(효용 언덕, 단기 비용 곡면, 시간축, 물가 축, 누락변수 등)이 SVG 곡선에서 솟아오르고, 주체(Households → Firms → Government → Central bank → Rest of world)와 식이 차례로 붙는다. **Fold flat**을 누르면 같은 위치의 평면으로 돌아간다.
- **Look inside(다이브)**: 그림 15개마다 단계별 해설 모드가 있다. 카메라가 위 → 비스듬히 → 단면 → 정면이나 축 방향으로 시점을 옮기고, 식의 항과 3D 형상을 연결한다. 대본이 있는 8개(수요공급, 제약최적화, 소비자 선택, 비용, 독점, 솔로, IS-LM, 회귀)에는 슬라이더 스윕이 있다. 예를 들어 가격을 움직이면 옆벽에 수요곡선이 그려진다. 평면 상태의 캡션 버튼으로도, 펼친 상태의 칩으로도 들어갈 수 있다. 조작은 휠과 화살표 키, 나가기는 Esc다.
- **주차 사다리와 교차점**: `curriculum.js`에 과목 17개(핵심 6: 원론·경제수학·미시·게임이론·거시·계량, 각론 11), 주차 138개, 교차점 9개가 있다. 각 주차는 질문, 답, 핵심 식, *Builds on / Used in* 링크를 가진다. 교차점은 일반균형과 후생, 집계, 오일러 방정식, 생산과 분배, 전략적 상호작용, 정보, 시장실패, 화폐·금리·환율, 식별의 9개다. 교차점마다 증명 사슬이 붙는다. 예를 들어 일반균형은 왈라스 법칙 → 브라우어 고정점 → 존재 → 제1·2후생정리로 이어진다. 각론의 순서는 MIT OCW(14.41, 14.54, 14.13 등), Berkeley Econ 182, Mishkin의 실제 강의계획을 따르고, 출처를 각 절에 적었다. `ladder.js`가 HTML의 `data-ladder` / `data-junction` / `data-fields` 자리에 이를 렌더한다.
- **실험대(bench, 펼친 공간)**: 페이지 법선을 따라 바로 위에서 내려오는 평행광이 그림자맵(PCSS 소프트 섀도)을 만든다. 그림 위에 선 장치의 그림자가 곧 교과서 그래프다.
  - **수요·공급**: 철사가 곡선을, 가격 막대가 가격선을 그림자로 드리운다. 막대는 초과수요 스프링에 밀려 dP/dt = κ[D − S]로 움직인다.
  - **에지워스 상자**: 부존점 ω를 축으로 예산 철사가 돈다. 두 가계의 구슬이 같은 선 위에 있으므로 왈라스 법칙이 보이고, 두 구슬이 만나는 점이 파레토 효율 균형이다.
  - **회귀**: 스프링이 막대를 최소제곱선으로 끌어당긴다.
  - 장치가 움직이는 동안 해당 그림은 html-in-canvas로 실시간 재렌더된 판(live plate)으로 바뀐다. 교과서가 그리지 않는 균형 사이의 상태까지 보인다.
- **Anatomy 블록과 무대(stage)**: 각 핵심 단원 뒤에 `Anatomy` 블록 41개가 들어간다. 단계별 도출과 그 단계에 쓰인 부품 카드(그래프·식)로 이루어진다. 펼치면 페이지 오른쪽 무대에서 같은 단계가 3D로 조립된다.
  - 이전 과목의 그래프 카드는 뒤쪽 선반으로 물러나 있다가 쓰일 때 날아와 조립된다. 카드 머리에는 출처(예: Micro 5)가 적혀 있다.
  - 대표 장면:
    - 수입 막대가 아치를 그리며 |ε| = 1에서 정점에 오른다.
    - 사람 20명의 막대로 잉여와 세금이 막는 거래를 보인다.
    - 공장 크기별 SRATC 평면이 겹쳐 LRAC 포락선이 된다(Viner).
    - 진입이 멈추는 점이 min LRAC다.
    - 이윤 언덕의 꼭대기가 MR = MC다.
    - 기업 수 n에 따라 독점에서 완전경쟁으로 이어지는 한 선이 된다.
    - B의 지도를 반 바퀴 돌려 A 위에 얹으면 에지워스 상자가 된다.
    - 케인지언 크로스를 r 축으로 쌓으면 균형점이 바닥에 떨어져 IS가 된다.
    - IS–LM을 P 축으로 쌓으면 AD가 된다.
    - NK 세 방정식은 Micro 5(Euler)와 Micro 9(마크업)에서 온다.
    - 각론마다 부품 카드와 모형이 함께 선다.
    - 마지막에는 세계 경제 고리(실물층과 금융층)가 놓이고, 각 주체 위에 그 주체를 설명하는 카드가 돌아온다.
  - 파일: `parts.js`(부품 카드 정의), `anatomy.js`(도출 텍스트), `stage.js`(조립·선반·구성물). Blender 모형은 19종이다.
- **기계(machine)**: 페이지 왼쪽에서 과목을 따라 조립된다.
  - 거시: 솔로 자본 탱크 → 소비 루프와 가계 → 중앙은행 다이얼 → 투자·정부 밸브(IS–LM, 구축효과) → 인플레이션 기둥과 기대 링(필립스) → 무역선과 준비금 탱크
  - 계량: 기록계
  - 각론: 노동자, 뱅크런 이중 우물, 공유지 접시
  - 기계는 독자를 따라 마지막 장까지 이동한다.
  - 주체는 Blender로 만든 흰 건축 모형이다(`tools/blender/make_agents.py` → `assets/agents/*.glb`). raw WebGPU용 GLB 로더는 `geo3d.js`에 있다.
- **7장 The record**: 실제 데이터 에피소드 다섯 개. 차트 커서가 읽는 줄을 따라 연·월 단위로 전진하고, 펼친 상태에서는 같은 날짜로 기계를 구동한다.
  - 한국 성장 1960–2025
  - 미국 필립스 곡선 1960–86
  - 1997 외환위기와 트릴레마
  - 2008 TED 스프레드와 뱅크런
  - 2021–26 금리와 전달 경로
  - 데이터는 `tools/fetch_data.py`가 ECOS·KOSIS·FRED·EIA·OpenDART에서 받아 `data/*.json`으로 만든다. 키는 루트 `.env`에만 있다(웹 비공개, `.gitignore`). 출처 코드는 `data/SOURCES.md`에 있다.
- 지난번의 탑·떠오르는 카드·실은 `?atlas`로만 볼 수 있다.
- 필요 환경: WebGPU와 HTML-in-Canvas를 지원하는 Chrome(156에서 확인). 지원하지 않으면 평면만 보인다.

```sh
python3 -m http.server 5182 --bind 127.0.0.1 --directory prototype/traditional
# → http://127.0.0.1:5182
```

### 프로토타입 ①: `prototype/supply-demand/`

빌드 도구 없이 raw WebGPU만 쓴 단일 페이지다. 이름은 supply-demand지만 지금은 런칭 페이지의 축소판이다.

- **히어로: 온톨로지 그래프.** 개념 72개와 관계 106개(`ontology.js`). 렌즈 4종(학제·주체·역사·수학) 사이를 모프하고, 과목 경로 4개(원론·미시·거시·CORE식)를 "왜 이 다음인가" 캡션과 함께 재생한다. ⤢ 개념을 누르면 그림 1의 해당 Expo 단계로 이동한다.
- **그림 1: 수요·공급.** 종이(2D)에서 Expo 4단계로 펼쳐진다. ① 곡면·비교정학, ② 시간·타토느망(RK4), ③ 소비자 8,192명 compute 집계, ④ 2시장 일반균형. ④는 퍼텐셜 곡면 위를 흐르는 입자 24,576개(compute)와 고유값에 따른 안정·안장 전환으로 보여준다.
- 두 화면 모두 **WebGPU 캔버스 하나에 뷰 두 개**로 그린다(결정 A2 검증). Apple GPU(Metal 3), DPR 2, MSAA 4x 기준 120fps.

```sh
python3 -m http.server 5180 --bind 127.0.0.1 --directory prototype/supply-demand
# → http://127.0.0.1:5180  (WebGPU 지원 브라우저 필요)
```

M0에서 `packages/engine`·`packages/models`·`packages/ontology`로 흡수한다. `renderer.js`와 `shaders.js`는 engine으로, `econ.js`는 models로, `ontology.js`는 ontology(+ content YAML)로 옮긴다.
