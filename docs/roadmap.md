## M0: 골격

- pnpm 모노레포, Astro 사이트, `packages/{engine,models,ontology}` 빈 패키지
- WebGPU 감지 → 미지원 안내
- 엔진 부트: 고정 캔버스 하나, 뷰 동기화, `grid` 패스
- **완료 조건**: 스크롤하는 본문 속 자리표시자 두 개에 각각 격자가 어긋남 없이 따라붙는다.

## M1: 수요·공급 (첫 공개)

- `line`, `point`, DOM 라벨 → 2D(종이) 수요·공급 + 곡선 이동 인터랙션
- 정사영 → 원근 dolly-zoom 모프, 종이 → 설계 공간 색 전환
- Expo 1 (시간축·타토느망·거미집), 2 (이질적 소비자 compute 집계), 3 (곡면·단면·편미분), 4 (다시장·야코비)
- 챕터 1개를 챕터 틀(vision.md §4)대로 완결 집필
- **완료 조건**: 2D ↔ Expo 4단계를 왕복할 때 끊김이 없고, GPU 집계가 TS 기준 구현과 오차 내로 일치한다.

## M2: 온톨로지 지도

- 스키마·검증(`packages/ontology`), 원론·미시·거시 핵심 개념 60~100개
- 히어로 그래프: 인스턴싱한 노드·간선, 렌즈 6종, GPU 모프
- 과목 경로의 `why`로 ①층 과목 페이지 초안 자동 생성
- **완료 조건**: 렌즈 전환이 부드럽고, 개념을 클릭하면 해당 챕터나 쇼케이스 단계로 이동한다.

## M3: 기준금리 전파

- 전파 경로 2D 도식 → 시장 층 공간화 + 입자 흐름
- 3방정식 NK 해법, 결정성 판정, 충격반응 곡면
- ECOS·FRED 스냅샷 스크립트, 금통위 이벤트 오버레이
- **완료 조건**: φ_π를 1 아래로 내리면 결정성이 깨진다는 것이 화면에서 보인다.
