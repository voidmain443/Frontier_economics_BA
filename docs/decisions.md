사용자 요청: "글꼴 디자인 등이 별로야. 영어로 전체 사이트를 제작해도 됨. 평면으로 설명하다가 Expo를 누르면 영상처럼 html-in-canvas로 레이아웃이 휘고, 그 위에 주체와 식이 하나하나 더해지면서, 원론에서 미시·거시·각론으로 스크롤할수록 공간과 식이 더해지게. Expo를 끄면 우리가 아는 2D 그림으로 설명을 다 달아줘. 지금은 기존 경제학이 학부를 어떻게 가르쳐 왔나를 설명하는 전체 페이지."

| # | 결정 | 내용 | 이유 / 근거 |

## 2026-10-29 밤: 네 번째 세션

사용자 요청: "과목들이 너무 한정적이야. 더 자세한 커리큘럼을 조사하고 주차별 수업 내용을 참고해서, 각 과목을 어떤 논리로 쌓아 가는지와 과목 간 접점(일반경쟁균형 존재조건, 파레토 효율, 왈라스 균형 등)을 보여 줘. 각론은 미시·거시에서 질문에 답하면서 생긴다. 2차원 교재 내용이 공간에 올라서고 셰이더가 실력을 보여 주면 좋겠어."

| # | 결정 | 내용 | 이유 / 근거 |
|---|---|---|---|
| D26 | 커리큘럼은 데이터 | **`curriculum.js` (COURSES, JUNCTIONS) → `ladder.js`가 렌더하고 → 아틀라스가 DOM에서 다시 읽는다** | 페이지가 곧 온톨로지다. 주차 하나는 질문, 답, 식, uses/feeds로 이루어진 노드이고, 교차점은 여러 과목의 주차를 잇는 하이퍼엣지다. 참조 무결성은 node 스크립트로 검사한다(깨진 링크 0). |
| D27 | 순서의 근거 | **실제 실라버스** | 서브에이전트가 MIT OCW, MIT 경제학과 실라버스, Berkeley, Yale, UC Davis, 서울대 졸업요건을 조사했다. 예를 들어 공공경제는 MIT 14.41 순서(외부성·공공재 → 정치경제 → 사회보험 → 조세)로 재배열했다. 각론마다 출처를 표시하고, 근거가 된 사실(14.04가 후생정리·존재·Gorman 집계로 끝남, 14.32가 RCT로 시작함, 서울대 2학년 전공필수)은 방주로 달았다. |
| D28 | 접점의 형식 | **교차점 = 증명 사슬 + 재등장 목록** | 예를 들어 "일반균형과 후생"은 다음 사슬로 이어진다. 연속·볼록 선호 → z(p) 연속·0차 동차 → 왈라스 법칙 → 단체(simplex) 위 브라우어 고정점(존재) → 제1후생정리 → 제2후생정리(분리초평면). 이어서 거시 2주차, 무역 HO, 공공 1주차, 재무 SDF에 다시 나타나는 것을 링크한다. 수학적 완결성이 다음 과목의 전제가 되는 모습을 보여 준다. |
| D29 | 공간을 쓰는 방식 | **과목 탑, 떠오르는 슬래브, 교차점의 실** | 빈 공간이 놀고 있다는 지적에 대한 답이다. 2D 카드가 두께 있는 슬래브로 떠오르고(힌지 기울기, 측면 글로우), 페이지에는 모눈 홈과 그림자가 남는다. 증명 단계는 부모 카드 위에 계단처럼 쌓인다(셰이더에 hinge와 stack을 추가). 탑의 층은 읽은 만큼 차오른다. 교차점은 카드에서 각 과목의 해당 층으로 실을 뻗고, 읽고 난 뒤에는 탑 사이의 다리로 남는다. |

| # | 결정 | 내용 | 이유 / 근거 |
|---|---|---|---|
| D30 | 공간의 원칙 | **공간에서 움직이는 모든 것은 페이지에 적힌 방정식의 해다** | 장식(탑, 글로우, 스파크, 블룸)을 걷어 냈다. atlas는 `?atlas`로만 남겼다. |
