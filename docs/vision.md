# 비전

## 1. 문제: 4년 뒤에는 그래프만 남는다

학부 경제학은 전 세계가 거의 같은 순서로 쌓는다. 원론 → 경제수학 → 미시 → 거시 → 각론. 그런데 4학년이 되면 대부분 수요·공급, IS-LM, AD-AS의 **그래프 모양**만 기억한다. 원인은 세 가지다.

1. **순서의 이유를 배우지 않는다.** 왜 소비자 이론 다음에 생산자 이론이 오는지, 왜 완전경쟁에서 독과점으로, 다시 공공재로 넘어가는지, 왜 미시 다음에 거시인지. 단계마다 쌓이는 논리가 시험 범위 뒤로 사라진다.
2. **서술의 틀이 없다.** 고시 경제학 답안이 쓰는 틀(개괄 → 현상 이해 → 이론 → 적용 → 변화 설명 → 예상 결과)로 현상을 해석하는 훈련이 없다. 문제 풀이만 하고 넘어간다.
3. **이론과 실제 경제가 끊겨 있다.** 기준금리 결정이 금융시장, 노동시장, 생산물시장으로 어떻게 번져 가는지를 이론의 체계 안에서 따라가 본 적이 없다.

## 2. 핵심 주장

**단순화는 좋은 틀이다. 단, 무엇을 접어 두었는지 알 때만.**

- **2D (종이)**: 교과서의 그래프. 변수를 고정하고, 시간을 지우고, 주체를 하나로 합친 결과다. 이 단순화 덕분에 배울 수 있다.
- **Expo (공간)**: 같은 그래프를 들어 올리면 접혀 있던 차원이 펼쳐진다. 곡선은 곡면의 단면이고, 곡선의 이동은 편미분이며, 균형으로 가는 과정은 미분방정식이고, 시장 여러 개가 얽히면 행렬이 된다.
- 다시 2D로 돌아오면 같은 그래프가 다르게 보인다. **이 왕복이 사이트의 핵심 경험이다.** 이 경험을 하고 나면 "경제학을 이 설계대로 처음부터 다시 배우고 싶다"는 마음이 들게 하는 것이 목표다.

## 3. 사이트 구성: 세 층

### ① 전통 학제의 '왜' (주된 층)

과목마다 한 장씩, 항목은 같다. **이 과목은 어디를 바라보는가 / 왜 이 자리에 오는가 / 무엇을 단순화했나 / 다음은 어디로 이어지는가.**

| 순서 | 과목 | 바라보는 곳 | 이 자리에 오는 이유 (초안) |
|---|---|---|---|
| 1 | 경제학원론 | 지도 전체 | 모든 개념을 한 번 얕게 훑어 나중에 깊이 들어갈 자리를 표시해 둔다. |
| 2 | 경제수학 | 언어 | 최적화, 미적분, 선형대수, 동학. 이후 모든 과목이 이 언어로 쓰인다. |
| 3 | 미시경제학 | 개별 주체의 선택 | 경제주체 → 선택 → 소비자·생산자 이론 → 시장 형태(완전경쟁 → 독과점) → 일반균형·후생 → 시장실패·공공재·정보. 합리성을 기준점으로 세운 뒤 그 기준에서 벗어나는 경우를 차례로 다룬다. |
| 4 | 거시경제학 | 집계와 시간 | 지표(측정) → 장기(성장) → 단기(변동: IS-LM, AD-AS) → 기대와 동학 → 정책. 개별 선택을 합치면 무엇이 새로 생기는가. |
| 5 | 계량경제학 | 이론과 현실 사이 | 이론이 말한 관계를 데이터로 측정하고 검증한다. |
| 6 | 각론 | 특정 시장·제도·공간 | 국제, 화폐금융, 재정·공공, 노동, 산업조직, 발전, 경제사·사상사. 같은 도구를 다른 대상에 적용한다. |

이 표는 서술의 출발점이다. 확정본은 온톨로지의 과목 경로([ontology.md](ontology.md))에서 관리한다.

### ② 새 경제학 커리큘럼들

CORE Econ(*The Economy* 등)을 비롯한 신경제학 커리큘럼들이 **무엇을 바꿨는지** 비교한다. 출발점(이론이냐 데이터·역사냐), 다루는 주제(불평등, 환경, 금융위기, 제도), 수학의 위치가 비교 축이다. 개념 그래프 위에 각 커리큘럼을 다른 경로로 그려서 같은 개념을 다른 순서로 지나간다는 것을 보여준다.

### ③ 새 과목 제안

후보만 있고 확정된 것은 없다. 예: 데이터로 읽는 경제, 계산경제학·시뮬레이션, 제도와 권력, 기후·환경경제, 플랫폼·디지털 경제, AI와 노동, 금융 안정과 거시건전성. 각 과목은 "기존 그래프의 어느 빈 곳을 메우는가"로 정당화한다.

## 4. 챕터 틀

고시 경제학의 서술 틀에 Expo 단계를 끼운다. MDX 챕터는 모두 이 순서를 따른다.

1. **개괄**: 이 개념이 다루는 질문
2. **현상**: 실제 경제에서 관찰되는 것 (데이터가 있으면 데이터로)
3. **이론 (2D)**: 교과서의 단순화된 모형
4. **펼침 (Expo)**: 그 단순화가 접어 둔 차원, 그리고 그것을 다루는 데 필요한 수학
5. **적용**: 현상을 이론으로 해석한다
6. **변화**: 외생 변수가 바뀌면 어떻게 되는가 (비교정학 → 동학)
7. **예상 결과**: 결론과 그 한계
8. **연결**: 온톨로지에서 이 개념의 다음 노드들

각주는 원전과 교재를 가리킨다(예: 마셜 『경제학원리』 1890). Shopify Editions 오른쪽 여백의 `Notes [1]` 패턴을 학술 각주로 바꿔 쓴다.

## 5. 쇼케이스 ①: 수요·공급

사용자가 처음 예로 든 그래프다. Expo 단계를 하나씩 올라갈 때마다 필요한 수학이 배지로 붙고, 그 배지는 경제수학 과목 노드로 연결된다.

| 단계 | 화면 | 필요한 수학 | 엔진 요구사항 |
|---|---|---|---|
| 0. 2D | 익숙한 X자. 소득이 오르면 수요곡선이 오른쪽으로 이동하고 새 균형이 생긴다. | — | 정사영 카메라, 굵은 선, 점, DOM 라벨 |
| 1. 시간축 | z축 = 시간. 균형으로 수렴하는 경로 `dp/dt = k(D(p) − S(p))`. 공급에 시차가 있으면 거미집 모형이 되고, 탄력성 비율에 따라 수렴하거나 발산한다. | 미분방정식, 차분방정식 | 원근으로의 카메라 모프, 궤적 선 |
| 2. 수요는 어디서 오는가 | 소득과 선호가 제각각인 소비자 N명(10⁴~10⁵)이 각자 효용을 극대화한다. 이 개별 수요를 수평으로 합치면 점구름에서 시장 수요곡선이 솟아오른다. | 최적화(라그랑주), 합 | compute 셰이더 집계, 인스턴싱한 점 |
| 3. 이동 = 편미분 | 수요함수 `D(p, I, …)`의 곡면. 2D 곡선은 소득 I를 고정한 단면이고, 곡선의 이동은 다른 단면으로 미끄러지는 것이다. 비교정학 `dp*/dI = −D_I / (D_p − S_p)` (음함수 정리). | 다변수 미적분 | 곡면 + 등고선, 단면 평면 |
| 4. 여러 시장 | 대체재·보완재 2~3개 시장의 일반균형. 초과수요 야코비 행렬의 고유값이 안정성을 결정한다. | 선형대수 | 벡터장 입자 흐름 |

## 6. 쇼케이스 ②: 기준금리 전파

| 단계 | 화면 | 필요한 수학 / 데이터 |
|---|---|---|
| 0. 2D | 전파 경로 도식: 기준금리 → 단기 시장금리 → 장기금리·대출금리·자산가격·환율·신용 → 소비·투자·순수출 → 총수요 → 고용(노동시장)·물가(생산물시장). 기대 경로를 별도로 표시한다. | — |
| 1. 공간 | 금융시장, 노동시장, 생산물시장이 층으로 쌓이고, 충격이 시차를 두고 입자 흐름으로 번져 간다. | 시간 지연 |
| 2. 모형 | 3방정식 뉴케인지언 모형을 브라우저에서 푼다. IS: `x_t = E_t x_{t+1} − (1/σ)(i_t − E_t π_{t+1} − r^n_t)`, NKPC: `π_t = β E_t π_{t+1} + κ x_t`, 테일러 준칙: `i_t = ρ + φ_π π_t + φ_x x_t + v_t`. 사용자가 φ_π를 바꾸면 충격반응이 곡면(변수 × 시차 × 계수)으로 변한다. 테일러 원칙은 결정성 조건, 즉 고유값 문제다. | 선형 기대 차분방정식, 고유값 |
| 3. 실제 | 한국은행 금통위 결정 이벤트와 CD91·국고채 3년·주담대 금리·원/달러의 실제 반응을 겹쳐 본다. 데이터는 빌드할 때 받은 스냅샷이다. | ECOS, FRED |

## 7. 비주얼 원칙

- **2D = 종이.** 학술 출판물 조판: 세리프 본문, 그림 번호, 여백 각주, 가는 검은 선.
- **3D = 설계 공간.** 어둠 위에 격자, 치수선, 떠 있는 수식, 빛나는 선.
- **전환이 곧 메시지다.** 종이가 어두워지며 공간이 되고, 돌아오면 다시 종이가 된다.
- Shopify Editions에서는 **기법과 구조만** 가져온다(각주 패턴, 섹션 사이로 비치는 그래프, 도면 미학, 공간화). 색, 타이포, 레이아웃은 독자적으로 만든다.
