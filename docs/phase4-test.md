# 4단계 확인: 전공자 관찰 계획

이 확인은 `docs/redesign.md`의 4단계를 실행하는 절차다. 판정 대상은 두 질문이다. 첫째, 전공자가 그림의 각 부분이 누구의 결정인지 답하는가. 둘째, 한 개념이 뒤에서 어디에 쓰이는지 답하는가. 같은 자리에서 접힘이 숨은 축을 전달하는지, 1부의 읽기 속도가 40분 목표에 맞는지도 기록한다.

참가자가 2~3명이므로 통계적 검정은 하지 않는다. 판정은 아래 '판정 기준'을 미리 정해 두고 그 기준과 비교한다. 기준은 세션 전에 고치지 않는다.

## 참가자

| 항목 | 조건 |
|---|---|
| 인원 | 2~3명, 한 명씩 따로 진행 |
| 자격 | 경제학 전공 3·4학년 또는 졸업 2년 이내. 원론·미시·거시를 이수했고, 각론을 1과목 이상 들었다. |
| 제외 | 이 사이트를 미리 본 사람, 사이트 제작에 의견을 준 사람 |
| 구성 | 가능하면 각론 이력이 서로 다르게 고른다(예: 금융 쪽 1명, 노동·개발 쪽 1명). |

## 준비

- 화면 1440×900 이상의 데스크톱, HTML-in-Canvas를 켠 Chrome. 세션 전에 1부를 한 번 접어 표제란 버튼이 보이는지 확인한다.
- 서버: `python3 -m http.server 5182 --bind 127.0.0.1 --directory prototype/traditional`, 주소 `http://127.0.0.1:5182/classical.html`.
- 사전·사후 질문지에 쓸 그림 네 장(2.1, 4.1, 6.2, 6.4)을 평면 상태로 인쇄한다. 인쇄본에는 캡션과 'Held fixed' 줄을 가린다.
- 화면 녹화와 음성 녹음은 참가자의 동의를 받은 경우에만 한다. 동의하지 않으면 관찰지 기록만 한다.
- 관찰자는 한 명이다. 진행 중 설명이나 힌트를 주지 않는다. 허용되는 개입은 아래 대본에 적힌 문장뿐이다.

## 진행 순서 (약 90분)

| 순서 | 시간 | 내용 |
|---|---|---|
| 0 | 5분 | 동의, 배경 질문(학년, 이수 과목, 각론 이력) |
| 1 | 10분 | 사전 질문지(사이트 없이, 인쇄본만) |
| 2 | 10분 | 1부 1~2단계를 평면으로 읽기. 접힘 버튼은 알려 주지 않는다. |
| 3 | 25분 | 1부 3~6단계 읽기. 2단계 끝까지 접힘을 찾지 못했으면 개입 문장 A를 읽는다. |
| 4 | 5분 | 1부 8단계에서 참가자가 고른 각론 한 과목 읽기 |
| 5 | 10분 | 2부 5절(은행 간 전염)에서 손실 슬라이더 조작, 3부 2절에서 평면도를 접고 문 하나를 눌러 과목 페이지로 이동 |
| 6 | 15분 | 사후 질문지(사이트를 닫고 인쇄본만) |
| 7 | 10분 | 인터뷰 |

읽는 동안 참가자에게 생각을 말로 하게 한다(think-aloud). 침묵이 30초 넘으면 개입 문장 B를 읽는다. 7단계(측정)는 시간 관계로 건너뛰고, 사후 질문지의 7.2 문항으로만 확인한다.

### 참가자에게 읽어 주는 말

> **시작:** 경제학 전공 과정을 설명하는 영어 사이트입니다. 사이트를 평가하는 것이지 참가자를 평가하는 것이 아닙니다. 읽으면서 떠오르는 생각을 소리 내어 말해 주세요. 모르는 것이 나와도 괜찮습니다. 제가 중간에 설명을 드리지는 않습니다.

> **개입 A (2단계 끝까지 접힘을 찾지 못한 경우):** 오른쪽 아래 표의 버튼을 한 번 눌러 보세요.

> **개입 B (30초 침묵):** 지금 무엇을 보고 계신지 말씀해 주세요.

> **5번 순서:** 2부 5절의 슬라이더로 첫 은행의 손실을 바꿔 보세요. 그다음 3부 2절의 평면도에서 페이지를 접고, 궁금한 방 이름 하나를 눌러 주세요.

## 사전 질문지

사이트를 보기 전에, 인쇄한 그림 네 장만 보고 답한다. 답은 관찰자가 받아 적는다. 같은 문항을 사후에 다시 묻는다.

**A. 이 그림의 각 부분은 누구의 결정인가** (그림마다 묻는다)

> 이 그림에서 각 선과 점은 누가 정한 것입니까? 가계, 기업, 정부, 중앙은행, 시장 중에서 골라 주세요. 아무도 정하지 않은 것이 있으면 그렇다고 말씀해 주세요.

**B. 이 개념은 뒤에서 어디에 쓰이나** (개념마다 묻는다)

> 이 개념이 나중의 어느 과목이나 어느 모형에서 다시 쓰였는지 기억나는 대로 말씀해 주세요.

| 번호 | 개념 | 사이트에서의 위치 |
|---|---|---|
| B1 | 예산선과 무차별곡선의 접점(라그랑주 조건) | 그림 2.1 |
| B2 | 오일러 방정식(현재와 미래 소비의 선택) | 그림 2.3 |
| B3 | 포락선 정리(장기 비용은 단기 비용들의 아래 껍질) | 그림 3.1 |
| B4 | 역선택(레몬 시장) | 그림 5.3 |
| B5 | 동시성(가격과 수량 자료는 수요곡선이 아니다) | 그림 7.2 |

## 사후 질문지

사전 질문지의 A와 B를 그대로 다시 묻는다. 이어서 C를 묻는다.

**C. 숨은 축** (그림 2.1, 3.1, 6.3)

> 페이지를 접었을 때 이 그림에서 무엇이 솟았습니까? 평면 그림은 그것을 어떻게 다루고 있었습니까?

**D. 사이트 전체**

> 1부의 여덟 단계가 어떤 순서로 쌓였는지 한두 문장으로 말씀해 주세요.

## 정답 기준

정답 기준은 사이트 본문에 적힌 내용에 맞춘다. 사이트에 없는 답이라도 경제학적으로 맞으면 '맞음(사이트 밖)'으로 따로 표시한다. 사이트 밖의 정답이 많으면 사이트가 아니라 참가자의 이전 지식에서 나온 답이다.

### A. 누구의 결정인가

| 그림 | 부분 | 정답 |
|---|---|---|
| 2.1 무차별곡선과 예산선 | 무차별곡선 | 가계(선호) |
| | 예산선의 기울기 | 시장(가격). 가계는 가격을 주어진 것으로 받는다. |
| | 예산선의 위치 | 가계의 소득. 이 그림 안에서는 주어진 것이다. |
| | 접점 | 가계의 선택 |
| 4.1 쿠르노 복점 | 각 반응곡선 | 각 기업(상대 수량에 대한 최적 대응) |
| | 이윤 등고선 | 각 기업의 목표 |
| | 교점 | 아무도 정하지 않는다. 두 기업의 선택이 서로 맞는 점(내시 균형)이다. |
| 6.2 IS–LM → AD | IS | 재화시장: 가계의 소비, 기업의 투자, 정부의 지출 |
| | LM | 화폐시장: 중앙은행의 화폐 공급과 가계의 화폐 수요 |
| | AD 위의 각 점 | 물가 수준마다의 IS–LM 균형. 아무도 고르지 않는다. |
| 6.4 중앙은행의 선택 | 필립스 곡선 | 기업과 노동자(기대 인플레이션과 가격 설정). 중앙은행이 받는 제약이다. |
| | 손실 그릇의 등고선 | 중앙은행의 선호 |
| | 선택된 점 | 중앙은행의 결정 |

부분마다 1점이다. 그림 2.1은 4점, 4.1은 3점, 6.2는 3점, 6.4는 3점, 합계 13점이다.

### B. 뒤에서 어디에 쓰이나

| 번호 | 사이트가 적은 뒤의 쓰임 (`classical.html`의 'Returns in' 방주와 `archive.html` 4절의 길) |
|---|---|
| B1 | 3단계의 비용 최소화, 그림 5.1(한 상자의 두 언덕), 그림 6.4(중앙은행), 8.4 재무경제(같은 접점이 자산 가격을 정한다) |
| B2 | 6단계(저축과 투자), 그림 8.2(경상수지), 그림 8.4(자산 가격), 그림 8.9(결정하는 날), 6.2의 현대적 IS 곡선 |
| B3 | 그림 3.2(진입), 산업조직의 자연독점, 그림 1.3(장기 수요) |
| B4 | 보험의 역선택, 은행의 차입자 선별, 노동의 신호 발송, 개발경제의 신용 부족 |
| B5 | 모든 각론의 식별 문제, 노동경제학과 경제사의 자연실험 |

개념마다 사이트에 적힌 쓰임을 하나 이상 말하면 1점이다. 사전에 0점이고 사후에 1점인 개념을 '새로 연결한 개념'으로 따로 센다.

### C. 숨은 축

| 그림 | 솟는 것 | 평면이 고정한 방식 ('Held fixed' 줄) |
|---|---|---|
| 2.1 | 효용 언덕 | 효용을 등고선으로만 읽는다. |
| 3.1 | 공장 규모 K | 단기 곡선 하나에 K 값 하나 |
| 6.3 | 기대 인플레이션 | 단기 곡선 하나에 기대 인플레이션 값 하나 |

솟는 것과 고정 방식을 모두 말하면 2점, 하나만 말하면 1점이다. 그림마다 최대 2점, 합계 6점이다.

## 판정 기준

| 대상 | 통과 | 실패 신호 |
|---|---|---|
| A. 누구의 결정인가 | 사후 13점 중 10점 이상인 참가자가 과반 | 사후 점수가 사전보다 오르지 않는다. |
| B. 뒤의 쓰임 | 사후 5개 중 3개 이상, 그리고 '새로 연결한 개념'이 1개 이상인 참가자가 과반 | 사후 답이 사이트 밖에서만 나온다. |
| C. 숨은 축 | 사후 6점 중 4점 이상인 참가자가 과반 | 솟은 것을 '장식', '효과'로 부르거나 축의 이름을 말하지 못한다. |
| 접힘의 발견 | 개입 A 없이, 또는 개입 A 한 번으로 접는다. | 접힘을 끄고 읽는다. "지금 어떤 모드인가"를 묻는다. |
| 접힘에서 돌아오기 | 접기 전과 같은 자리의 평면으로 돌아왔다고 말하거나 그렇게 행동한다. | 돌아온 뒤 위로 스크롤해 읽던 곳을 찾는다. |
| 읽기 속도 | 1~6단계가 35분 이내다(1부 40분 목표에 7·8단계 몫을 남긴 값). | 1~6단계가 45분을 넘는다. |

A, B, C가 모두 통과하면 4단계를 마친다. 하나라도 실패하면 실패한 항목과 관련된 그림과 글을 고치고, 새 참가자 1~2명으로 그 항목만 다시 확인한다.

## 세계 시제품을 함께 볼 때

세계 시제품(W1)이 준비된 세션에서는 인터뷰 뒤에 5분 동안 시제품의 1~3단계를 접은 채로 보여 준다. 질문과 판정은 `docs/world.md`의 '확인에 더할 질문'을 따른다. 이 5분은 사전·사후 점수에 넣지 않는다.

## 결과 정리

세션이 끝날 때마다 관찰지를 `docs/phase4-results.md`에 옮긴다. 참가자는 P1, P2, P3으로만 적고 이름과 학교는 적지 않는다. 세 세션이 끝나면 판정 기준표의 각 행에 통과 또는 실패를 적고, 실패한 행마다 고칠 그림과 글을 `docs/decisions.md`에 새 결정으로 남긴다.
