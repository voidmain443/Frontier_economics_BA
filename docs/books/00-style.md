# 한국어판 문체: 교과서 문어체 (D116)

한국어판은 영어판을 옮긴 것이지만, 한국어로 쓴 경제학 교과서의 문장으로 읽혀야 한다. 영어의 어순, 품사, 문장 경계를 그대로 따른 표현을 번역투라고 한다. 이 문서는 한국어판에서 고친 번역투의 유형과 고치는 방식을 형태론, 통사론, 화용론, 음운론의 순서로 정리한다. 6절은 비유를 수학 용어로 바꾸는 표, 7절은 용어집, 8절은 고친 예, 9절은 점검 방법이다.

내용은 영어판과 같다. 명제, 수치, 인용, 연도, 그림 번호, 링크는 더하거나 빼지 않는다. 문장의 구조, 어순, 문장 경계는 한국어에 맞게 바꾼다. 영어 한 문장을 두 문장으로 나누어도 되고, 두 문장을 한 문장으로 합쳐도 된다. 같은 단락 안에서는 문장 순서를 바꾸어도 된다.

## 1. 기본

- 한다체로 쓴다. 그림, 모형, 정리는 현재 시제로 서술하고, 역사적 사실은 과거 시제로 서술한다.
- 비유, 과장, 감탄을 쓰지 않는다.
- 용어는 페이지에서 처음 나올 때 '한국어(English)'로 쓰고, 그 뒤로는 한국어만 쓴다.
- 청유형("~을 살펴보자")은 단계나 절이 바뀌는 자리에서만 쓰고, 한 페이지에서 드물게 쓴다.

## 2. 형태론

**2.1 복수 접미사 '-들'.** 한국어 명사는 '-들'이 없어도 복수를 가리킬 수 있다.
- 무생물 명사에는 '-들'을 붙이지 않는다. 예: 곡선들, 가격들, 점들, 모형들, 균형들.
- '모든, 여러, 많은, 각, 수사'가 앞에 오면 사람 명사에도 붙이지 않는다.
- '것들'은 쓰지 않는다. 가리키는 대상을 명사로 밝혀 '변수, 값, 조건, 내용, 부분, 대상'처럼 쓴다.

**2.2 '것'의 남용.** '~하는 것이다'로 끝나는 문장은 '~이다', '~한다', '~을 뜻한다'로 바꾼다. 다만 '빠뜨린 것', '고정한 것'처럼 대상을 하나의 명사로 묶을 수 없을 때는 '것'을 쓴다.

**2.3 '가지다, 갖다'.** 영어 have를 옮긴 '가지다'는 '있다', '주어지다', '~으로 이루어지다'로 바꾼다.
- 예: "선호와 예산을 가진 의사결정자" → "선호와 예산이 주어진 의사결정자".
- 예: "기업은 그림 3.1의 비용을 가진다" → "기업의 비용은 그림 3.1과 같다".

**2.4 피동.** 다음 세 가지를 쓰지 않는다.
- 겹피동: 되어지다, 쓰여지다, 보여지다.
- 행위자를 밝히는 '~에 의해'.
- 능동으로 쓸 수 있는 '-어지다'. 예: "그려진다" → "그린다, 그렸다".

**2.5 수와 분류사.**
- 명사를 앞에 두고 수와 분류사를 뒤에 둔다. 예: "교과서 22권", "기업 세 곳", "질문 세 가지".
- 열 이하의 수는 고유어 수사에 분류사를 붙여 쓴다(세 가지 질문, 두 기업). 열을 넘는 수는 아라비아 숫자로 쓴다(22권, 301장).
- 분류사 없이 수사만 뒤에 붙이지 않는다. 예: "작업 여덟" → "여덟 가지 작업". 단, "시장 하나"는 1단계의 이름으로 그대로 쓴다.
- 영어 관사 a, one을 옮긴 '하나의 N', '한 N'은 쓰지 않는다. 예: "하나의 소득에서" → "소득 수준 하나를 정하고". 수를 세는 '한 사람', '한 단위'는 그대로 쓴다.

**2.6 어휘.** 다음 동사와 연결어를 바꾼다.

| 번역투 | 교과서 |
|---|---|
| 잰다(measure) | 측정한다 |
| 푼다(relax an assumption) | 완화한다 |
| 푼다(solve) | 푼다, 구한다 |
| 세운다(derive, build) | 도출한다, 구성한다 |
| ~을 필요로 한다 | ~이 필요하다 |
| 그래서 | 따라서, 그러므로 |
| 하지만 | 그러나 |
| 또 | 또한 |

## 3. 통사론

**3.1 관형절 겹침.** 명사 앞의 관형절이 두 겹을 넘으면 문장을 나눈다.
- 예: "서로에게서 사는 기업들은 … 버는 것과 가진 것이 다른 가계들은" → "서로 거래하는 기업은 …. 소득과 자산이 다른 가계는 …".

**3.2 '~에 대한, ~에 관한'.** 조사나 동사로 푼다.
- 예: "그려지지 않은 사람들에 대한 합" → "그림에 없는 사람의 이득을 더한 값".
- 예: "미래 소비에 대한 수요" → "미래 소비의 수요". 경제학 용어로 굳은 '~에 대한 수요'는 그대로 둔다.

**3.3 '~을 통해', '~와 함께', '~ 중 하나', '~로부터'.**
- '~을 통해'는 '~으로'로 쓴다. 실제로 거쳐 가는 경로를 말할 때만 '~을 거쳐'로 쓴다.
- '~와 함께'는 '~와' 또는 '~하면서'로 쓴다.
- '~로부터'는 '~에서'로 쓴다.

**3.4 쌍점(:).** 쌍점은 표, 라벨, 캡션의 범주어(위:, 아래:, 파랑:)에만 쓴다. 문장 안에서 항목을 늘어놓을 때는 다음과 같이 쓴다.
- "~으로는 ~이 있다", "~은 다음과 같다"로 쓴다.
- 예: "주체(agents)는 결정한다: 가계, 기업, …" → "주체(agents)는 결정을 내리는 단위이다. 가계, 기업, …이 여기에 속한다."

**3.5 동격 'X, 곧 Y'.** 한 단락에 한 번 넘게 쓰지 않는다. 그 밖의 경우에는 '즉'을 쓰거나 관형절로 바꾼다.

**3.6 문장 길이.** 한 문장이 공백을 포함해 90자를 넘으면 나눌 수 있는지 본다. 반대로 영어의 짧은 문장이 줄줄이 이어지면 다음과 같이 합친다.
- 연결어미(-고, -며, -므로, -지만)로 한 문장으로 합친다.
- 예: "페이지는 2차원이고 경제는 차원이 많다." "그림이 단면인 것은 어쩔 수 없어서다." → "지면은 2차원이고 경제에는 변수가 많으므로, 그림은 단면일 수밖에 없다."

## 4. 화용론

**4.1 무생물 주어와 행위 동사.** 다음 명사를 행위 동사의 주어로 쓰지 않는다.
- 해당 명사: 그림, 표, 페이지, 절, 단계, 과목, 모형, 정리, 바퀴.
- 해당 동사: 보여 준다, 말한다, 묻는다, 적는다, 가르친다, 허락한다, 요구한다, 원한다, 준다, 만든다(사동).
- 바꾸는 방법은 네 가지다.
  1. 처소나 도구로 바꾼다. 예: "그림 2.1에서 ~을 볼 수 있다", "그림 2.1에는 ~이 그려져 있다".
  2. 행위자를 생략한 능동문으로 쓴다. 예: "그림마다 아래에 고정한 조건을 적었다".
  3. '~에 따르면'으로 쓴다. 예: "후생경제학 제1정리에 따르면 경쟁균형은 파레토 효율적이다".
  4. '~에서는 ~을 다룬다'로 쓴다. 예: "게임이론에서는 ~을 분석한다".
- 개념을 주어로 하고 서술 동사(나타낸다, 뜻한다, 해당한다, 성립한다, 결정된다, 이동한다)를 쓰는 문장은 한국어 교과서에서도 쓴다. 증명을 서술하는 "~임을 보인다"도 쓴다.

**4.2 대명사.** 그것, 그것들, 그들, 이들을 쓰지 않는다. 명사를 되풀이하거나 생략한다. 한국어는 문맥으로 알 수 있는 주어와 목적어를 생략한다.

**4.3 '은/는'과 '이/가'.** 다음 기준으로 고른다.
- 처음 도입하는 대상에는 '이/가'를 쓴다.
- 이미 나온 대상이나 화제, 대조에는 '은/는'을 쓴다.
- 문장마다 '은/는'으로 시작하는 단락은 첫 문장 뒤의 화제어를 생략할 수 있는지 본다.

**4.4 정의.** 용어를 도입할 때는 "~을 X(English)라고 한다"로 쓴다.
- 예: "그 상태가 내시 균형(Nash equilibrium)이다" → "이러한 상태를 내시 균형(Nash equilibrium)이라고 한다".

**4.5 영어의 명령문.** "Give each step a column." 같은 영어의 명령문은 다음과 같이 옮긴다.
- 조건문으로 쓴다. 예: "계단 한 칸을 기둥 하나로 세우면 ~이 된다".
- 행위자를 생략한 서술문으로 쓴다. 예: "계단 한 칸마다 기둥을 하나씩 세웠다".

**4.6 독자 지칭.** 독자를 부르지 않는다. '우리'는 꼭 필요할 때만 쓴다.

## 5. 음운론

**5.1 조사의 이형태.** 숫자, 로마자, 그리스 문자, 기호 뒤의 조사는 그 말을 읽는 소리에 맞춘다. 은/는, 이/가, 을/를, 과/와, 으로/로가 해당한다.

| 끝소리 | 예 | 붙는 조사 |
|---|---|---|
| 모음 | 2(이), 4(사), 5(오), 9(구), A~K, O~Z(에이, 비, …, 와이), %, λ, θ, π, σ | 는, 가, 를, 와, 로 |
| ㄹ | 1(일), 7(칠), 8(팔), L(엘), R(알) | 은, 이, 을, 과, 로 |
| 그 밖의 받침 | 0(영), 3(삼), 6(육), 10·20(십), 100(백), 1000(천), M(엠), N(엔), ε(엡실론) | 은, 이, 을, 과, 으로 |

- 예: "그림 3.7은", "D115를", "A3을", "IS–LM은", "GDP는", "6.3%가", "(3, 6)으로".

**5.2 괄호 뒤의 조사.** 괄호 안의 원어는 읽지 않는 것으로 보고, 괄호 앞의 말에 조사를 맞춘다.
- 예: "수요곡선(demand curve)은", "『경제분석의 기초』(Foundations, 1947)와".
- 좌표나 수식의 괄호는 괄호 안의 끝소리에 맞춘다. 예: "(불진입, 싸움)은", "(u − 5)를".

**5.3 '의'의 연쇄.** 한 명사구 안에서 '의'를 두 번 넘게 잇지 않는다.
- 예: "그 과목의 단원의 그림의 축" → "그 과목 단원에 실린 그림의 축".

**5.4 같은 소리의 반복.** 한 문장에서 같은 조사나 어미가 세 번 넘게 반복되면 다음 방식으로 줄인다.
- 문장을 나눈다.
- 나열을 '·'로 묶는다(시간·화폐·정부).

## 6. 비유를 수학 용어로

영어판의 그림 설명에는 곡면이나 제약을 일상어로 부르는 비유가 있다. 한국어판은 교과서에서 쓰는 수학 용어로 쓴다.

| 영어판 | 한국어판 |
|---|---|
| hill (utility, profit) | 효용 곡면, 이윤 곡면 |
| fence (budget) | 예산 제약면(예산선 위에 세운 수직면) |
| top, peak of the hill | 최고점 |
| bowl (loss) | 손실 곡면(아래로 볼록한 곡면) |
| ridge | 능선(곡면의 능선은 수학 용어로 쓴다) |
| arch (outline along the fence) | 단면 곡선 |
| shadow | 투영 |
| wall (a curve that does not depend on the hidden axis) | 수직면 |
| tent | 역V자 모양 |
| floor | 하한 |
| door (a link in a cell) | 링크 |
| rises out of the page | 높이로 올라온다 |
| lights (a cell) | 밝게 표시된다 |
