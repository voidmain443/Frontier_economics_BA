# Data sources

Generated by `tools/fetch_data.py` (standard-library Python). Rerun it to refresh; API keys are read from `../.env` at run time and never written here.

URL templates show the API key as `{KEY}`; `{START}`/`{END}`/`{YEAR}` are period placeholders. Time keys: annual `YYYY`, monthly `YYYY-MM`, weekly `YYYY-MM-DD` (week-ending Friday). Annual means cover closed calendar years only; a year with a missing month is flagged in its note.
